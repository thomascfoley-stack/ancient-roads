## The bound

Rule of three, 95% lower confidence bound ≈ 1 − 3/n: 0 breaches at n=100 supports **~97%**,
stated with its n. It does NOT support the ≥99% bar, which still needs ~300 clean cases of
genuinely new vectors, not rephrasings.
